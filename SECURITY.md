# Security Policy

## Supported versions

Security fixes are applied to the latest release on the default branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Send a concise report to [lordxyn@proton.me](mailto:lordxyn@proton.me) with reproduction steps, impact, and any suggested mitigation.

You will receive an acknowledgement within five business days. Please allow time for triage and a coordinated fix before disclosure.

## Scope

Reports involving authentication, authorization, tenancy isolation, snapshot/WAL integrity, graph and metadata access controls, network transports, or denial of service are in scope.
