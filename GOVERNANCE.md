# Governance

HoloSphere is currently maintained by ArcMoon Studios.

Maintainers set release policy, review changes to persistence and protocol contracts, and make final decisions when consensus is not reached. Design proposals are discussed openly; changes affecting public APIs, snapshot formats, replication semantics, or security boundaries require maintainer approval and migration notes where applicable.

As the contributor community grows, this document will be updated to describe delegated maintainership and voting processes.
